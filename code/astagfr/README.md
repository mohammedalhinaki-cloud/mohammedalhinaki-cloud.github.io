# Astagfr — selected Kotlin source

This folder contains selected source files from the Astagfr Android project for technical review.

- `MainActivity.kt`: application entry point and Compose setup.
- `IstighfarViewModel.kt`: counter state, goal handling and local persistence calls.
- `IstighfarScreen.kt`: Jetpack Compose screen layout and interaction.
- `IstighfarPreferences.kt`: SharedPreferences-backed local storage.

These files are provided as **source examples, not a complete standalone build**. The complete Android project contains additional UI components, resources, configuration and dependencies.
